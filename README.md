Estou concluindo o **Técnico em Informática para Internet integrado ao Ensino Médio** no Instituto Federal Catarinense, Campus Araquari (2024–2026). ## Projetos em destaque

### Pires Panificadora · TCC
Sistema de pré-pedidos e gestão de vendas para a cantina do IFC Araquari. O aluno reserva os itens antes do intervalo, paga online e retira o pedido com QR Code; a administração controla estoque, promoções e relatórios.

- **Meu papel:** desenvolvedor fullstack (API e PWA), em dupla com [Gabriel Sombrio](https://github.com/gaSombrio)
- **Destaques:** login com Google + JWT, pagamento via Mercado Pago, retirada por QR Code, máquina de estados dos pedidos, baixa automática de estoque, notificações e relatórios de vendas
- **Stack:** Vue 3 · Pinia · PWA · Django · DRF · PostgreSQL · Cloudinary
- 🔗 [Aplicação](https://frontend-pires.vercel.app) · [Frontend](https://github.com/Panificadora-Pires/frontend-pires) · [Backend](https://github.com/Panificadora-Pires/backend-pires) · [Documentação](https://github.com/Panificadora-Pires/.github)

### Fluxo · Hackathon (DreamTeam-2k26)
Plataforma de gestão de projetos em equipe, com quadro Kanban, chat, chamadas em tempo real, pastas de arquivos e brainstorm.

- **Meu papel:** foco no frontend, responsável pelo **quadro Kanban** (que apresentei aos jurados), com contribuições no backend para integrar tarefas, anexos e fotos de perfil
- **Stack:** Vue 3 · Pinia · GSAP · Django · DRF · Channels (WebSocket) · JWT
- 🔗 [Aplicação](https://fluxo-beige-three.vercel.app) · [Frontend](https://github.com/DreamTeam-2k26/frontend) · [Backend](https://github.com/DreamTeam-2k26/backend)

### Brookiê · Projeto Integrador
E-commerce mobile-first para venda de cookies e brownies artesanais.

- **Meu papel:** desenvolvi a maior parte do frontend e do backend, incluindo upload de fotos com Cloudinary, deploy no Render com PostgreSQL e correção de uma falha de escalonamento de privilégios na API de usuários
- **Stack:** Vue 3 · Pinia · PWA · Django · DRF · PostgreSQL · Cloudinary
- 🔗 [Aplicação](https://brookie-frontend.vercel.app/) · [Frontend](https://github.com/EquipePI-3info2/frontend) · [Backend](https://github.com/EquipePI-3info2/backend)

### Sede do Medo
Plataforma para descobrir, explorar e avaliar filmes de terror, consumindo a API do TMDB, com busca, favoritos, histórico e player de trailers.

- **Stack:** Vue 3 · Pinia · Vue Router · Axios · TMDB API
- 🔗 [Aplicação](https://sededomedopi.vercel.app/) · [Repositório](https://github.com/Equipe-Hackaton/pi_SededoMedo)

### Join-Ville · Hackathon IFC Araquari
Plataforma que reúne os eventos de Joinville por categoria, com cadastro restrito a empresas com CNPJ válido e filtros por data, categoria e avaliação.

- **Stack:** Vue 3 · Django · DRF · JWT
- 🔗 [Aplicação](https://join-ville-dusky.vercel.app/) · [Frontend](https://github.com/Equipe-Hackaton/Join-ville) · [Backend](https://github.com/Equipe-Hackaton/backend-hackaton)

### Plataforma do Hackathon · Fábrica de Software IFC
Sistema para organizar o hackathon do IFC: edições, inscrições, equipes, envio e avaliação de projetos.

- **Meu papel:** componentes de interface e telas (sidebar, paginação, seletores, cadastro de projetos)
- **Stack:** Vue 3 · TypeScript · Vuetify
- 🔗 [Frontend](https://github.com/fabricadesoftware-ifc/fabricaHackathon_frontEnd)
